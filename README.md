# Molecular Minimalist Portfolio

This project is a Next.js based portfolio showcasing AI, ML, and genomics work.

## Prerequisites

- **Node.js** version 18 or later

## Setup

Install dependencies:

```bash
npm install
```

## Development

Run the development server:

```bash
npm run dev
```

## Media Hosting

This project uses local media files stored in the public directory. For videos, you can also embed external videos from platforms like YouTube or Vimeo using their embed URLs.

## Optional Commands

- Lint the project:

```bash
npm run lint
```

- Type check the project:

```bash
npm run type-check
```
